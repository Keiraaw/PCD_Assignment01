## Project Overview
This program demonstrates the resolution reduction process (*down-sampling*) using Max, Average, and Median methods, as well as resolution enhancement (*up-sampling*) utilizing Nearest Neighbor, Bilinear, and Bicubic interpolation techniques. 

Two primary images are used as testing datasets:
- `Sky.jpg`
- `Pattern.jpg`

## File Structure
- `PCD_Assignment01.ipynb`: The main source code (Jupyter Notebook) containing the algorithms and *subplot* visualizations.
- `PCD_Assignment01_Report Analysis.pdf`: A detailed analytical report comparing the visual outcomes of the various *resampling* methods.
- `Sky.jpg` & `Pattern.jpg`: The original image files (*raw data*) used for processing.

## Dependencies
To execute this notebook locally, ensure the following libraries are installed in your Python environment:
- `numpy`
